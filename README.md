# Data Mining Course Platform (MITQ2506)

A standalone, zero-build static educational website for learning **Data Mining & Knowledge Discovery** in **Uzbek (`O'zbekcha`)** and **English**.

## Features
- **15 Complete Course Modules** (`index.html`, `topic.html`) covering KDD, Preprocessing, Decision Trees, Naive Bayes & k-NN, Evaluation Metrics, Association Rules, K-Means, Hierarchical & DBSCAN, Anomaly Detection, Ensemble Methods, Text Mining, Web Mining, Stream Mining, Privacy-Preserving DM, and Capstone Project.
- **Interactive Reveal.js Slides via CDN** (`slides.html`) with bilingual switching, syntax-highlighted Python lab code, fragments, and keyboard navigation.
- **Interactive Quiz Engine** (`quiz.html` and per-topic quizzes) with 75 bilingual questions, instant feedback, explanations, and saved scores via `localStorage`.
- **Practice Questions & Live Browser Calculators** (`practice.html`) featuring Min-Max/Z-score, Entropy/Gini, Confusion Matrix, and Market Basket calculators plus 14 worked practice exercises.

## Usage
Open `index.html` directly in any browser, or host via GitHub Pages. No Node.js, Docker, or build tools required.
